# User Stories

Each story lives in its own file named `NNN-short-title.md`, where `NNN` is the next free three-digit number (e.g. `001-run-smoke-preset.md`). Numbers are never reused. Before rebasing onto or merging into another branch, renumber any story whose number that branch already uses.

To add a story, copy [TEMPLATE.md](./TEMPLATE.md), fill it in, and add a row to the table below. Keep the status here in sync with the story file.

**Statuses:** Proposed, In Progress, Done, Rejected
